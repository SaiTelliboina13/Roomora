# Roomora – 3D Interior Design Studio

Roomora is a web-based interior design platform that allows users to explore and customize room layouts through an interactive 3D studio.

## Features

- Responsive SaaS landing page.
- Interactive 3D room visualization.
- Multiple room types, including living room, bedroom, kitchen and dining, bathroom, office, and kids' room.
- Furniture customization and placement.
- Furniture colour, rotation, and size controls.
- Save and reset design functionality.
- Contact/demo request form.

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- Three.js
- React Three Fiber
- React Three Drei
- Lucide React

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project:
   ```bash
   cd roomora
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Production Build

```bash
npm run build
```
